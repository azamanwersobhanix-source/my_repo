# Azam SB Portfolio

A responsive red + black developer portfolio built with HTML5, CSS3, JavaScript and Bootstrap 5.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static web server.

## GitHub projects

The project gallery reads public repositories from the GitHub REST API.

1. Open `script.js`.
2. Set `GITHUB_USERNAME` to your exact GitHub handle.
3. Reload the page.

The gallery hides forked repositories and shows the most recently updated public projects.

## Deploy

This is static-site friendly and can be deployed to GitHub Pages, Netlify, Vercel, Cloudflare Pages, or any normal static host.
